# Tables

* [Products](./products.md) - Master product catalog entries
* [Product Variants](./product_variants.md) - Purchasable SKUs (color/switch-type/size) per product
* [Product Pricing](./product_pricing.md) - Live, promo-aware price per SKU
* [Warehouses](./warehouses.md) - Fulfillment warehouse locations
* [Inventory](./inventory.md) - Per-SKU, per-warehouse stock levels
* [Customers](./customers.md) - Customers who have placed orders
* [Orders](./orders.md) - Order headers and current status
* [Order Items](./order_items.md) - SKU line items within an order
* [Shipments](./shipments.md) - Shipment/parcel tracking
* [Order Status History](./order_status_history.md) - Append-only order status audit trail
* [Return Requests](./return_requests.md) - Customer return/refund requests
* [Return Window Policy](./return_window_policy.md) - Return window & condition rules per category
* [Refunds](./refunds.md) - Refunds issued against return requests
* [Item Condition Flags](./item_condition_flags.md) - Per-item return-eligibility exclusion flags
